Estado: desarrollo en curso en `feat/quartz-0.14-text-file-form-field` (2026-10-27). No merge/publicación: la reconciliación de la versión 0.13 sigue pendiente en PR #44.

Una familia coherente por minor: no añadir contenido de otras familias aunque parezca barato.

## 14-01 — FormField

- Ids deterministas y cableado `aria-labelledby/describedby` entre etiqueta, ayuda y error y el control proyectado; atributos de estado desde `NgControl` (invalid/touched/dirty/disabled) vía la entrada opcional `/forms`; funciona con inputs nativos y controles Quartz.

## 14-02 — Input OTP

- N ranuras sobre un input oculto: avance/retroceso, pegado con filtro por patrón, `autocomplete=one-time-code`, estado activo/caret por ranura, salida de completado. Adaptador Forms (`string`).

## 14-03 — Autofill

- Directiva de detección de autofill con atributo y salida; no-op en servidor; limitaciones entre navegadores documentadas.

## 14-04 — Subida de archivos

- Zona de soltar con contador dragenter/leave, filtrado `accept`, `multiple`/`directory`, drop con `DataTransfer` real, asociación con el selector nativo y alternativa por teclado. Salida de archivos; no se añade CVA.

## 14-05 — Receta de búsqueda

- Documentar y probar la composición `role=search` + botón de limpiar con retorno de foco.
