# Spec: 0.2.0 Navigation, Selection and Controls

- **Status:** Implemented
- **Branch:** feature/0.2.0-navigation-selection-controls
- **Date:** 2026-08-31
- **Release target:** `@quartz-headless/core@0.2.0` and `@quartz-headless/primitives@0.2.0`

## Audit Summary

- Core already had the right widget-agnostic foundations for this slice: `CollectionStore`
  for ordered/disabled item navigation, `Overlay` for popup rendering, `Dismiss` for
  layered close behavior, `Focus` helpers for restore, and `Directionality` for logical
  inline navigation/placement.
- Dialog carried its own body overflow counter. That behavior belonged in Core because
  dialogs, drawers and future modal surfaces need to coordinate per `Document`.
- Listbox, Combobox and Select share concepts, but not one focus model. Listbox owns a
  tabbable container with active-descendant, Combobox keeps DOM focus on an editable input,
  and Select uses roving focus inside a popup. No public Core selection abstraction was
  added; each primitive composes `CollectionStore` directly where useful.
- Menu and Popover did not need API changes for this release. Their current Overlay and
  Dismiss usage remains the model for popup primitives.
- Presence/exit animation remains a future foundation. None of the new primitives need it
  for correctness, and implementing it here would expand the release beyond navigation,
  selection and controls.

## Implemented

- Core `scroll-lock`: `createScrollLock(document)` returns `{ locked, lock(), unlock(),
destroy() }`, supports nested locks, multiple consumers, arbitrary unlock order, SSR no-op
  behavior and original body overflow restoration.
- Dialog now uses Core `createScrollLock()` instead of a private body overflow counter.
- Select: single-value, button-triggered popup listbox with controlled `value`/`open`,
  disabled options, object values, `compareWith`, `displayWith`, typeahead and Overlay
  positioning.
- Tabs: `qzTabs`, `qzTabList`, `qzTab`, `qzTabPanel` with automatic/manual activation,
  horizontal/vertical orientation, disabled tabs, ARIA relationships and RTL-aware
  horizontal keys through Collection + Directionality.
- Accordion: `qzAccordion`, `qzAccordionItem`, `qzAccordionTrigger`, `qzAccordionPanel`
  with single, single-collapsible and multiple state, disabled items, optional `region`
  panels and header arrow navigation.
- Switch: button-first `qzSwitch` with `checked` model, disabled state, `role="switch"` and
  `aria-checked`.

## Release Notes

- Public exports, CLI registry, docs routes/sidebar, package verification and demos were
  updated for ScrollLock, Select, Tabs, Accordion and Switch.
- `@quartz-headless/primitives` now peers on `@quartz-headless/core@^0.2.0`.
- No 0.2.0 breaking changes are expected inside the scoped packages beyond the peer range
  bump from `^0.1.0` to `^0.2.0`.
