# 0.7.0 — Core consolidation acceptance

Status: **see "Release readiness" at the end** (filled in with the exact verified state).
Date: 2026-10-22. Baseline: `main` @ `1e14aab` (0.6.0).

## Changes delivered

### Focus (CORE-01)

- `isFocusable(el)` now means "can receive **programmatic** focus right now": connected, matches the
  focusable selector or carries a `tabindex` attribute (so `tabindex="-1"` is a valid script target,
  a plain `<div>` is not), and is not disabled, not in a disabled `<fieldset>` (legend exempt), not
  `input[type=hidden]`, not under `hidden` / `inert` / `aria-hidden="true"`, not `display:none` on
  itself or any ancestor, not `visibility:hidden`.
- `getFocusableElements(container)` is the **sequential (Tab)** set: `isFocusable` plus non-negative
  tabindex.
- `createFocusRestorer().restore()` never reclaims focus for a removed/unfocusable target.
- `createFocusTrap` is stack-aware per Document (only the newest live trap handles Tab) and yields
  to focus inside an overlay portal (`[data-qz-overlay-container]`).

### Layers (CORE-02)

- `createDismissController`: one physical event is claimed by one dismissal.
- Dialog restores focus on close only when it still owns focus.
- Contract: `docs/ai/specs/v1-layer-composition.md`.

### Overlay (CORE-03)

- Pending frames are cancelled on close/destroy and session-guarded; destroyed refs cannot reopen.
- Dismiss layer registered synchronously in `open()` (stack order = open order) and once per session
  (previously re-registered when arming outside-pointer, which could move it above a newer layer).
- Host `ViewContainerRef` destruction closes the overlay (wrapper removed, `closed$` once).
- Open overlays reposition on window resize, on size change of the overlay content or the anchor
  element (ResizeObserver), and on scroll when `closeOnScroll` is `false`; updates coalesce to one
  per frame. An anchor removed from the document closes the overlay.
- `OverlayTriggerDirective.open()` only reports `opened` when the overlay really opened (no-op
  without a window).
- `flipAxis` now has real semantics (see Decisions).

### Collection (CORE-04)

- Removing the active item activates the nearest enabled neighbour (next sibling, else previous).
- Navigation from an active item that was disabled in place continues from its position instead of
  jumping to an end; roving tab stop falls back to the same neighbour.
- Typeahead with no match no longer clears the active item; the typeahead buffer expires even when
  no `Document` was supplied; `destroy()` leaves no timer and disables further typeahead.
- Re-registering an item/id replaces the entry in place; unregistering an unknown item is a no-op.

### Viewport / Directionality (CORE-05)

- `ViewportService` tracks the window `resize` event. The previous `ResizeObserver` on `<html>` did
  not fire for height-only window changes, leaving `height()` stale. `destroy()` is idempotent and
  makes later `observe()` calls inert.
- `resolveDirection` skips invalid `dir` values (`auto`, typos) and keeps walking up, like the
  browser; implemented as an attribute walk so it works in limited server DOMs.

### Tooling

- `scripts/api-guard.js` (run by `pnpm verify:build`): declaration-based export/signature snapshot
  of both packages in `docs/api/snapshots/`.
- `pnpm verify:consumer` now runs the Angular AOT compiler (`ngc`, `strictTemplates`) on the
  installed tarballs with a Core overlay/focus/dismiss/scroll-lock fixture.
- E2E fixture `/e2e-layers` and `e2e/core-contracts.spec.ts`.

## Decisions

| Decision                         | Choice                                                                                                                                                          |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isFocusable` semantics          | Kept the name; narrowed to the documented programmatic-focus contract (was "not disabled/hidden").                                                              |
| Collection recovery              | Next sibling first, else previous, else none.                                                                                                                   |
| Overlay repositioning            | Automatic for resize, content/anchor size change, scroll (when not dismissing). Pure layout shifts that change neither size nor scroll need `updatePosition()`. |
| `flipAxis`                       | `main`: opposite side; `cross`: opposite alignment (`-start`↔`-end`); `both`: side, alignment, then both; `none`: never. First candidate that fits wins.        |
| Anchor removal                   | Closes the overlay.                                                                                                                                             |
| Host destroyed while open        | Overlay closes, releases everything, `closed` emits once.                                                                                                       |
| Directionality mutation tracking | No `MutationObserver`; explicit `refresh()` / `set()` documented and tested.                                                                                    |
| Background isolation             | No `inert`/`aria-hidden` on siblings in 0.7 (deferred, see below).                                                                                              |
| New public abstractions          | None.                                                                                                                                                           |

## Breaking changes and migration

No export, signature or selector changed (`diff` of the declaration snapshots against a 0.6.0
build is empty). Behavioural changes that can affect consumers:

- `isFocusable(plainDiv)` is now `false` (it was `true`). Give the element a `tabindex` (usually
  `-1`) before focusing it, or focus a real control.
- `OverlayRef`/trigger with `closeOnScroll: false` now follows scrolling instead of staying put.
- `flipAxis: 'cross' | 'both'` now flip as documented instead of acting like `'main'`.
- `ViewportService.height()` now updates on height-only window changes.
- `CollectionStore.typeahead()` with no match keeps the active item (it used to clear it).

## Known limitations

- No background `inert`/`aria-hidden` for modals.
- Overlay does not follow position-only layout shifts (no size change, no scroll).
- Oversized overlays clamp to the start margin (no shrink/`max-height` handling).
- Directionality does not observe `dir` mutations.
- Hydration/SSR are checked only with mocked documents; real SSR/hydration is the 0.10 milestone.
- AOT smoke covers one narrow Core fixture, not the 0.10 compatibility matrix.
