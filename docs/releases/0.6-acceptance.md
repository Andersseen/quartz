# 0.6 contracts acceptance note

Status: implementation in progress. Date: 2026-09-05.

## Closed in this pass

- Public surface inventory created at `docs/api/public-surface.md`.
- Initial v1 scope decisions created at `docs/api/v1-scope.md`.
- Draft family contracts created for Core, floating/feedback, selection/controls and Forms.
- Coverage configuration moved to the root Vitest config and `coverage.all` was removed from
  package configs.
- Coverage now includes both library source trees from the root workspace and uses baseline
  thresholds so regressions fail before the aspirational v1 targets are reached.
- Migration notes toward the local 0.5 baseline were added without claiming a published registry
  release.

## Still open before declaring 0.6 fully done

- Product approval of conditional v1 areas: Splitter, Drag and drop, Virtual scroll, Combobox,
  Tree, Slider, Toggle, ToggleGroup, Sidebar, Navbar and Stepper.
- Public API declaration diff and Angular template type fixture from `06-06`.
- Changelog reconciliation once the exact published 0.5 state is confirmed.
- CI workflow update to make the new coverage gate mandatory in pull requests if CI does not
  already run `pnpm test:coverage`.

## Baseline thresholds
