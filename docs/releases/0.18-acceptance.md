## Release pipeline (implemented, not yet exercised on GitHub)

`package` job → `release-artifacts` (tarballs, `release-manifest.json`, `SHA256SUMS`) → consumer jobs install those tarballs (hash re-verified) → `publish` downloads the same
files (builds nothing), verifies manifest hash/commit/ancestry, plans against the registry (fail closed), publishes Core then Primitives with `--tag latest|next --provenance`,
reads back integrity and dist-tag; `release` binds the tag to the validated commit. Concurrency group `quartz-npm-release` (no cancel). Not exercised: the workflow itself
(`workflow_dispatch` publish path, provenance, `id-token`) cannot run until merged; the PR run exercises `package` and the consumer jobs.
