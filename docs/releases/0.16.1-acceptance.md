# 0.16.1 acceptance record

Patch release of `main` for `@quartz-headless/core` and `@quartz-headless/primitives`. Status: **prepared, not published.**

## Why a patch

Consumers on Angular 22 get `invalid` peers from the published 0.16.0 (`^21.0.0`) and need `legacy-peer-deps`, which hides real missing peers. The
release also carries the Tooltip press fix and the library bug fixes made since 0.16.0 (SSR ids, Combobox, Accordion, Sidebar, NavigationMenu).

A hotfix from tag `v0.16.0` was rejected: that tree has no release tooling (`scripts/release/`, `consumer/`, `e2e:ci`), so it cannot pass the guarded
workflow, and its code was never verified on Angular 22 and still has the SSR id leak.

Versioning: the maintainer chose a patch over a minor (2026-11-16). Against the published 0.16.0 tarballs, re-snapshotted with the current API guard:
**0 BREAKING, 2 ADDITIVE** (`QzIdGenerator` in Core; public member `AccordionItemDirective.blurredThisTask` in Primitives), Forms entry unchanged. Both
additions are incidental to bug fixes. The peer change replaces `^21.0.0` with `^21.2.0 || ^22.0.0`; Angular 21.0/21.1 never built (Toast template
arrow function), so the lower bound corrects the declared range rather than dropping a working version. This is an exception to RELEASE_RUNBOOK §10.5
("a peer range change is not a patch"), recorded here.
