## 1. Implemented contracts

| Area        | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Numeric     | One normalization for Slider and RangeSlider: repaired bounds/step, grid = `min + n·step` ∪ `{max}`, integer-scaled arithmetic (no drift), `NaN` → `min`, `±Infinity` → bound, `min == max` pins the value, `floor`/`ceil` snapping for range constraints.                                                                                                                                                                                                                                       |
| Gestures    | Pointer capture; the gesture ends on `pointerup`, `pointercancel`, `lostpointercapture`, disabling and destroy. Only the primary button starts a drag. The pointer wins over an external model write during a drag (the write applies, the next `pointermove` overrides it). The root sets `touch-action: none`.                                                                                                                                                                                 |
| Committed   | `valueChangeCommitted` (Slider: `number`; RangeSlider: `{ low, high }`; ToggleGroup: scalar/`null`/array) and `pressedChangeCommitted` (Toggle) fire **once per user change**; programmatic writes, focus movement and repeats of the same value are silent. Slider/RangeSlider commit continuously while dragging.                                                                                                                                                                              |
| RangeSlider | Models `[(low)]`/`[(high)]`, canonical value `{ low, high }`. Invariants: grid values in `min..max`, `low ≤ high`, `high − low ≥ minDistance`; external violations are repaired with **high winning**; a user action moves only its own thumb, clamped against the other. Press on a thumb grabs it; press on the track grabs the nearest thumb (ties → `low`; coincident thumbs → by pointer side). Per-thumb `aria-valuemin/max` reflect the other thumb and `minDistance`; no extra tab stop. |
| ToggleGroup | `allowDeselection` (single mode, default `true` = previous behaviour); mode-aware `isPressed`; removing a pressed item never rewrites the value; arrows move focus without committing.                                                                                                                                                                                                                                                                                                           |
| Forms       | `SliderControlDirective` (`number`), `RangeSliderControlDirective` (`{ low, high }`), `ToggleControlDirective` (`boolean`), `ToggleGroupControlDirective` (scalar/`null` single, array multiple). In `QUARTZ_FORMS`; `@angular/forms` stays optional.                                                                                                                                                                                                                                            |

## 2. Confirmed defects fixed

1. **ToggleGroup rendered `aria-orientation` on `role="group"`** (not allowed by ARIA). Found by the first axe scan of the new fixture; removed (`data-qz-orientation` remains).
2. **Slider could not reach `max`** with `Home`/`End`/`PageUp` when the range was not a multiple of `step` (`0..10`, step `3` stopped at `9`). `max` is now on the grid.
3. **Slider stepping accumulated float error** (`0.1 + 0.2`); stepping now uses scaled integers.
4. **Slider `NaN`/`Infinity`/zero or negative `step`/swapped or non-finite bounds** produced `NaN` percentages or stuck values; all repaired.
5. **Slider drag could outlive its trigger**: a drag was not ended by `lostpointercapture` or by disabling the slider mid-gesture.
6. **ToggleGroup `isPressed` ignored `type`** (an array value pressed items in single mode).
7. A pressed ToggleGroup item could not be kept pressed in single mode (implicit deselection) — now configurable.

## 3. New public APIs

See `docs/api/public-surface.md` ("0.11.0 additions"). Snapshots: +9 primitives exports (RangeSlider family and types), +4 Forms directives; no removals or signature changes. CLI: new `range-slider` entry (`deps: ['slider']`, so the CLI copies both folders); `slider` also copies the new `slider-interaction.ts`. The Forms entry point is still **not** distributed by the CLI (documented).

## 4. Breaking changes and migration

None for exports or selectors. Behaviour to check (details in `/docs/migration/upgrading-to-0-11`): grid now includes `max`; invalid input repaired; `touch-action: none` on slider roots; `aria-orientation` removed from the ToggleGroup host; mode-aware `isPressed`. Primitives peers on `@quartz-headless/core@^0.11.0`.

## 5. Forms semantics

| Adapter     | Value                           | `reset()` / `null`                          | `onChange`                               | Touched                                       |
| ----------- | ------------------------------- | ------------------------------------------- | ---------------------------------------- | --------------------------------------------- |
| Slider      | `number`                        | shown at `min`; control keeps `null`        | each key step / new value while dragging | focus leaves the slider                       |
| RangeSlider | `{ low, high }` (never a tuple) | full `min..max` shown; other shapes ignored | each user change of either thumb         | focus leaves the control (not between thumbs) |
| Toggle      | `boolean`                       | `false` (same as Switch)                    | once per activation                      | blur                                          |
| ToggleGroup | scalar/`null` or array by type  | nothing pressed; control keeps `null`       | once per activation                      | focus leaves the group                        |

`writeValue` is silent everywhere; `setDisabledState` blocks input (and ends a drag).

## 7. Volt parity classification changes

`slider` P → **V**, `range-slider` M → **V**, `toggle` C → **V**, `toggle-group` P → **V** (V 8 → 12; C 2 → 1; P 9 → 7; M 13 → 12). Recorded differences from Volt (pinned `7c76ef3`, unchanged): RangeSlider Forms value is `{ low, high }` (Volt: `[low, high]`) and `null` resets to the full range (Volt ignores it); ToggleGroup single uses a scalar/`null` (Volt: always `string[]`); Quartz is structural, so Volt's built-in `ariaLabel*` inputs map to `aria-label` on the Quartz elements.

## 8. Known limitations

- Continuous commit while dragging (no on-release event); N-thumb sliders, ticks and value tooltips are out of scope.
- `pointercancel`/`lostpointercapture` are exercised as dispatched events, not produced by a physical pointer.
- Window resize during a drag is handled by re-reading geometry on every pointer event; it has no dedicated browser test.
- Manual screen-reader review, real SSR/hydration (0.17) and Angular 22 remain open.
- The Forms entry point is not available through `quartz add`.
- **Pre-existing flake, not caused by 0.11:** the `health › no console errors` test in Firefox intermittently reports one `ERROR Error` from `core-*.js` while loading `/docs/primitives/select` under parallel load (reproduced on `main` @ `820bcf8`: 6 of 24 repeated runs with 4 workers; CI runs 1 worker with retries). Source not identified.
- The Doqs integration surfaced no new reproducible issue for these playgrounds (`docs/integrations/doqs-feedback.md` unchanged).
