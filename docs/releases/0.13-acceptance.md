Status: **version reconciliation merged; post-merge E2E failed and release remains pending**. Main workflow `40494140662` passed quality, unit/coverage, consumer and full E2E jobs, then deployed and created a GitHub release. Because manifests still declared 0.12.0, that workflow published the current 0.13 implementation as both npm `0.12.0` packages and created `v0.12.0`. The 0.12 version is immutable. PR #44 merged the 0.13.0 package manifests and Primitives' Core peer range `^0.13.0`. Post-merge workflow `40526751145` passed quality and unit/consumer checks but failed E2E after 323 passes, 309 failures and one flaky result; deploy, npm publish and release jobs were skipped. Many failures report missing expected page elements (for example `#open-a` on `/e2e-layers`).

## Implemented scope

- Toolbar: one roving Tab stop, orientation/RTL arrows, Home/End, disabled skipping, live order refresh and removal focus recovery.
- NavigationMenu: named disclosure navigation, one active flyout, delayed hover, trigger keyboard navigation, Escape focus restoration, outside dismissal, Core Overlay positioning and teardown.
- Pagination: one-based page model, page-count clamping, native disabled boundaries, `aria-current="page"` and focus recovery.
- Accordion: container disabled, horizontal orientation/RTL, required-open `aria-disabled` behavior, DOM order and focus recovery.
- Sidebar: focused regression coverage for collapsed/closed distinction, mobile Escape, focus trap and scroll-lock cleanup.
- Public exports, CLI source-copy entries, strict consumer fixture, Doqs documentation, demos and playgrounds.
