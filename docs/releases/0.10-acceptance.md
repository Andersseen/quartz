# 0.10.0 — Advanced selection + Doqs documentation: acceptance

Status: **implemented on `feat/quartz-0.10-selection-doqs`; merge, release and deployment outcomes are recorded in the PR.**
Date: 2026-10-24. Starting point: `main` @ `32c55ab4ab97d7514b0031e2d51f9d64520b5c28` (0.9.0).

> **0.10 accepted ≠ Quartz 1.0 compatible with Volt UI.** After this release **8 of the 46** inventory rows
> are verified-equivalent (V): 0.9's five plus `select`, `listbox` and `combobox`.

## 1. Advanced-selection changes

| Area     | Delivered                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Select   | `multiple` + `[(values)]` (the single `value` model is untouched), `closeOnSelect` (default `!multiple`), `valuesChangeCommitted`, `selectedValues`/`selectedLabels`/`isEmpty`, `data-qz-placeholder`, `aria-multiselectable`. Labels derive from the value through `displayWith`, so unrendered options keep their label. Scroll dismissal arms two frames after open (a scroll already in flight cannot close the popup it opened). |
| Groups   | `qz{Select,Listbox,Combobox}Group` / `GroupLabel` / `Separator`: `role=group` + `aria-labelledby`; none register with the Collection, so navigation and typeahead skip them. Separators are decorative (`aria-hidden`): axe showed ARIA forbids `separator` inside a listbox.                                                                                                                                                         |
| Listbox  | Sections/headers; single mode stays scalar, array translation is a Volt-adapter concern.                                                                                                                                                                                                                                                                                                                                              |
| Combobox | `multiple`/`values`, `allowDeselect`, query vs. value separation, `queryChanged`, `status`, IME guard (`compositionstart/end`, `isComposing`, keyCode 229), `valueChangeCommitted`/`valuesChangeCommitted`/`touched`, native `disabled`, `createLatestRequest()` (abort + discard stale responses for consumer-owned fetching; Quartz does not fetch).                                                                                |
| Core     | Virtual scroll no longer throws when measured on a server DOM (found by prerendering the docs).                                                                                                                                                                                                                                                                                                                                       |

## 2. Forms behaviour

`SelectControlDirective` handles `multiple` (array, `[]` after emptying, `null`/reset shown as empty). New
`ComboboxControlDirective` (also in `QUARTZ_FORMS`): value = committed selection, never the text; typing does not
notify; editing a selected value's text clears it and notifies once with `null`; `writeValue` is silent and syncs
the text; `reset()` clears selection and text; touched on blur or outside close; `setDisabledState` disables the
input. Evidence: `forms.advanced.spec.ts`, `e2e/selection.spec.ts` (Reactive Forms). `@angular/forms` remains an optional peer.

## 5. Documentation migration (Doqs)

- **Engine:** `@doqs/analog@0.10.0` (published, installed from npm, pinned). Host: Angular 21.2.6, Analog 2.9.2 (upgraded from 2.4.8 only to satisfy the peer), Vite 8.0.8. No Doqs source, git, workspace or tarball dependency.
- **Ownership:** one router: Analog file routes for `/`, `/components`, fixtures; `doqRoutes()` for `/docs/**`. Legacy `(docs)` pages, custom layout, sidebar, demo wrapper, code-block and web-editor were removed after their coverage moved.
- **Content (`src/content/docs`):** Getting started (2), Guides (7, one source-backed via `doq content`), Core (10: the 7 former pages + Collection, Focus, Dismiss), Primitives (20), Reference + generated API (3 entry points, 237 symbol pages), Migration (2). All 27 former component/foundation pages migrated with their examples; their live demos run as `::demo` components (same `data-testid`s, behaviour specs retargeted). Nine playgrounds of real primitives: Select, Listbox, Combobox, Checkbox, Switch, RadioGroup, Tabs, ToggleGroup, Slider.
- **Search:** Pagefind built from the final prerender (`doq-search`); per-symbol API pages are excluded from the index by `scripts/prepare-search.mjs`.
- **URLs:** old root URLs (`/dialog`, `/select`, …) → 301 to `/docs/core|primitives/<name>` through `public/_redirects` (no SPA fallback; unknown paths are 404). Verified by E2E and `docs:check`.
- **Prerender/hydration:** HTML contains the content; demos are `@defer (on idle)` wrappers so the server renders placeholders only; no hydration warnings on the checked routes. Behaviour fixtures use `ngSkipHydration`.
- **Cloudflare:** `wrangler.toml` and `deploy.yml` deploy `dist/analog/public`; the npm publish job is unchanged and independent. Deployment result: recorded in the PR after merge.
- **Light/dark:** the site is dark-only (Doqs follows the tokens); no theme switch was added.
- **Feedback:** `docs/integrations/doqs-feedback.md` (no P0/P1; 6 × P2, 6 × P3, issue drafts).

## 6. Known limitations

- Combobox has no chips/Backspace removal and no built-in fetching; Select/Combobox do not virtualize.
- Docs search ranks the Doqs-indexed guides only (API symbols are reachable through the sidebar and API index pages).
- Doqs has no per-page `aria-current`, `<main>` or sidebar scroll persistence; the first two are host-fixed (`role=main`), the third restored by the shell.
- SSR/hydration of every primitive across an Angular version matrix is **not** claimed (0.17).
