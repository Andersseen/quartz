## Implemented public surface

- FormField structural directives wire stable consumer-provided root IDs, labels, descriptions, errors and compatible native/Quartz control hosts. Optional Forms observation lives in `@quartz-headless/primitives/forms`.
- InputOTP uses one text input and presentational slots, exposes a string model and completion event, and has an optional Forms adapter.
- Autofill detection observes configurable animation events, exposes a data attribute and state output, and forwards a value-change input event for supported autofill transitions that omit `input`.
- File selection enhances a native file input and adds a dropzone wrapper with nested drag state, `accept` filtering, multiple-file rejections, picker access and no upload behavior.
- Search remains an HTML/Angular composition recipe. Native input and textarea remain native.

## Decisions and limitations

- No generated IDs are used. Consumers provide a unique stable field root ID and explicit description/error IDs to keep server and client references deterministic without module-global state. Server-rendered ID equivalence has not been directly tested.
- Autofill detection is best-effort and depends on configured browser animation events. It is not a universal browser signal; genuine OS/browser autofill was not exercised.
- File filters are UX only. Files are not read, uploaded or security-validated. Directory selection uses the native `webkitdirectory` attribute where supported; directory drops are not traversed.
- File upload has no mandatory CVA. File selection and rejection are outputs.
- InputOTP is an input primitive, not an authentication service. Values are not persisted or logged.
- This branch carries the 0.13.0 manifests from updated `main`; bump to 0.14.0 only after the 0.13.0 release is verified.
