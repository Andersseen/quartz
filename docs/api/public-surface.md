`333ee70 docs: add v1 roadmap`. This file inventories what the current
`public-api.ts` barrels expose; it is evidence for v1 decisions, not a promise that every export
will remain stable.

## CLI registry surface

The CLI exposes all core and primitive areas above through `REGISTRY`, with `internal: true` only
on `collection`, `focus`, `dismiss` and `directionality`. That means a v1 export decision must
also decide whether the CLI copy surface follows the same stable catalogue or stays explicitly
best-effort source copy.

## Symbols requiring explicit v1 decision

- `QZ_MENU_SERVICE_PROPERTY` is exported from `menu.directive.ts` internally but not from the
  package public API. Keep it internal unless a real consumer needs it.
- `defaultComboboxDisplayWith` and `defaultComboboxFilter` are exported from source but not from
  the public barrel. Keep them internal or export intentionally; do not let implementation details
  become public by accident.
- Service classes exported from primitives expose public methods beyond directives. Their method
  contracts need snapshots or type examples before 1.0.

## 0.7.0 contract notes

The exported names and signatures are unchanged from 0.6.0 and are now enforced by declaration
snapshots (`docs/api/snapshots/core.json`, `primitives.json`, checked by `pnpm verify:build`;
regenerate deliberately with `node scripts/api-guard.js --update`). Behaviour clarified in 0.7.0:

- `isFocusable`: programmatic-focus target (connected, focusable selector or `tabindex`, visible,
  enabled, not inert/aria-hidden). `getFocusableElements`: the Tab-order subset.
- `createFocusTrap`: only the newest live trap per Document handles Tab.
- `OverlayRef`/`OverlayTriggerDirective`: repositions on resize, content/anchor resize and (with
  `closeOnScroll: false`) scroll; closes when the anchor leaves the document; `flipAxis` values
  `main | cross | both | none` are all honoured; destroyed refs cannot reopen.
- `CollectionStore`: nearest-neighbour active recovery; typeahead no-match keeps the active item.
- `ViewportService`: `resize`-driven size; inert after `destroy()`.
- `resolveDirection`: ignores invalid `dir` values.

## 0.8.0 contract notes

Exported names and signatures are unchanged from 0.7.0 (`docs/api/snapshots/` is byte-identical).
Additive and behavioural changes:

- `DialogConfig.ariaLabel?: string` — accessible name when there is no title element. A dialog's
  `aria-labelledby` / `aria-describedby` are written only when their target exists.
- Modal Dialog isolates the background with `inert` (`aria-hidden` fallback), see
  `docs/ai/specs/v1-floating-contract.md` §9.2.
- `TooltipDirective` no longer owns the host's `aria-describedby` binding; it appends/removes its
  own id and preserves consumer ids. A `data-qz-tooltip` attribute marks the string tooltip element.
- `PopoverTriggerDirective`: the `open` model is reset to `false` when a disabled trigger refuses
  to open; disabling an open trigger closes it.
- `ToastContainerComponent` styles read `--qz-toast-inset`, `--qz-toast-gap`,
  `--qz-toast-max-width` and `--qz-toast-z-index` (defaults unchanged).
- `ToastService.pause()` freezes the exact remaining time; `resume()` on an unpaused toast is a no-op.
- `OverlayRef` no longer re-destroys a view Angular is already destroying.
