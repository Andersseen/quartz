Lazy Loading (per level)

Pass loadChildren and mark unknown branches with hasChildren: true. A node fetches its children the first time it is expanded — once: collapsing and expanding again renders from memory. The context exposes loading, error and retry() as signals, so a failed branch stays collapsed with a retry affordance instead of spinning forever. expandAll() deliberately only expands what is already loaded.

@if (hasChildren) { @if (loading()) { ◌ } @else if (error()) { ↻ } @else { {{ expanded ? '▼' : '▶' }} } } @else { } {{ hasChildren ? (expanded ? '📂' : '📁') : '📄' }} {{ node.label }} @if (loading()) { loading… } @if (error()) { {{ messageOf(error()) }} }

Requests issued: {{ requestCount() }} — collapse a folder and open it again, the counter stays put. restricted/ always fails, click ↻ to retry.
