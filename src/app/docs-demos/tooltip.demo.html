Need interactive content?

A tooltip (role="tooltip") must never contain focusable or interactive content per WAI-ARIA — that's what Popover is for. Quartz removed the earlier tooltipInteractive option for exactly this reason; use Popover for links, buttons, or any content a user needs to interact with.

Delay

Adjust tooltipDelay and tooltipHideDelay to control how quickly the tooltip appears and disappears.
